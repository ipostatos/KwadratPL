### Данные

- **3 источника:** OLX (API) + Otodom (`__NEXT_DATA__`) + Morizon (ld+json). Всё stdlib, без ключей. ~1500–1660 сырых объявлений за прогон.
- **Умный дедуп (v2, по A/B на живых данных):** корзина (город, тип, цена) → кластеры площади ±2 м², дисквалификаторы по комнатам/району, ascii-фолд районов. Старый точный ключ прятал 63 реально разные квартиры — исправлено (прод: 1498 → 1552 лота).
- **Фетчер = GitHub Actions** в публичном репо `kwadratpl-fetcher` (OLX отдаёт 403 с VPS IP). Крон `*/5`, фактически тикает раз в 1–2.5 ч (троттлинг GH). **Вотчдог** `fetch_watchdog.py` написан и задеплоен: дёргает workflow_dispatch при данных старше 35 мин — ⏳ **ждёт токен** (см. §3).

### Бэкенд

- FastAPI + aiogram в одном процессе (systemd `kwadratpl-api`, VPS Hetzner). SQLite.
- Распилен из монолита 1183 строк: `config/db/auth/matching/texts/bot/ai_usage/widget_tokens` + `routers/{health,widget,analyze,subs,listings}` — app.py 66 строк.
- Rich-уведомления (sendPhoto + карточка фактов + «почему совпало» на 4 языках), фолбэк на текст, кнопка «…и ещё N».
- Виджет-API (connect/state/action/disconnect), AI-статистика `/stats` для админов, бюджет-контроль ($ по токенам).
- Аудит безопасности пройден (2 ревью-агента): XSS, инъекции, whitelist ссылок, лимиты тел, atomic-записи — всё закрыто.

### Инфраструктура и качество

- **CI:** pytest (25 тестов) + JS-смоук (`check-app.mjs`, 36 ключей API) + i18n-чек → **автодеплой на VPS** по push в main (paths-filter: доки не рестартят прод). Pre-commit хук дублирует CI локально.
- **webapp/app.js распилен** на `js/{core,subs,price,ai}.js` без сборщика. Vanilla навсегда — Next.js отвергнут осознанно (`frontend/` удалён).
- Ночные бэкапы БД (7 дней), hardening systemd, Caddy с лимитами.

### Лендинг + домен + SEO (16–17 июля)

- **site/** — статический промо-сайт, ноль JS, 4 языка, полная SEO-обвязка (canonical, hreflang, OG, JSON-LD, llms.txt, PWA-манифест).
- **Домен kwadratpl.pl** куплен (domena.pl), NS → Vercel, www/staging → 308 на apex, SSL.
- **Поисковики:** GSC верифицирован + sitemap принят; IndexNow (Bing/Яндекс/Copilot) — отправлено дважды.
- **Донаты:** Buy Me a Coffee, фирменная жёлтая кнопка, «на оплату домена и сервера», 4 языка.
- **SEO-аудит** (9 параллельных агентов): Health Score **74/100**, ни одного Critical в технике. Все быстрые фиксы применены в тот же день:
  - llms.txt актуализирован (врал: «6 городов, 4 языка» → 8 и 5, FAQ-блок для AI-цитирования);
  - лого 311 KB → 17 KB WebP, скриншоты → WebP (−660 KB), preload, кэш на год → **PSI 100/100, LCP 2.41s → 0.9s**;
  - `/privacy/` на 4 языках (single source из webapp) + строка об операторе в футере (E-E-A-T);
  - H1 с ключевым запросом ×4, виджет-код локализован PL/UA/EN;
  - schema: WebApplication + WebPage-узлы, security-заголовки (CSP, XFO, HSTS preload), таб-таргеты 44px.

### 7a. Communities Фаза 1 — шаги для запуска (когда появится время)

Код полностью готов и задеплоен (community.py, коммит ca296cb), просто выключен. Когда будет возможность:
1. Создать публичную супергруппу в Telegram.
2. Добавить `@KwadratPLBot` админом с правом отправки сообщений.
3. Узнать её chat_id (отрицательное число) — любой `@getidsbot`, или `getUpdates` после того как бот получит там сообщение.
4. Прописать `COMMUNITY_CHAT_ID` (+опционально `COMMUNITY_LANG`, дефолт `ru`) в `/opt/kwadratpl/.env` + `systemctl restart kwadratpl-api`.

Дальше бот сам начнёт публиковать в группу объявления ≥12% дешевле медианы района/города (тот же алгоритм, что бейдж «ниже рынка» в приложении) — живая витрина находок + growth-канал, задел под будущую Фазу 2.

## 4. Планы и приоритеты

### P1 — сейчас (разблокировка)
1. Токен вотчдога (§3.1) — 5 минут, максимальный эффект на UX уведомлений.
2. GSC-доступ (§3.2) — 2 минуты, включает мониторинг индексации нового домена.

### P2 — SEO-стратегия лендинга (по итогам аудита)
1. **Портировать гайды из Mini App в `site/guides/`** — лучший контент проекта (кауция, red flags, чек-лист) невидим краулерам, а SERP-ниша «как снять без агента» / «мошенники при аренде» / «жильё для украинцев» свободна от конкурентов-ботов. Контент уже написан на 4 языках — работа только по вёрстке.
2. **8 городских страниц** (`/warszawa/`…) из мёртвых чипов — единственный путь к city-запросам + внутренняя перелинковка.
3. **Внешний авторитет = 0:** каталоги Telegram-ботов, Product Hunt, статья в стиле devby (конкуренты там уже есть), YouTube-демо → всё в `Organization.sameAs`.

### P3 — рост и деньги (план Bot API 10.2, утверждён ранее)
1. **Stars-подписка** — монетизация (спроектировать премиум-фичи).
2. **Communities + Ephemeral** — рост.

### P4 — фон
Визуальная полировка (тестируют user и друзья) · by/-лендинг · контраст ссылок · упомянуть kwadratpl.pl в GitHub-repo homepage и описаниях бота · нативный WidgetKit (Mac + $99) — когда-нибудь.
